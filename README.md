# khakha.dev

Personal site for Shubham Khakha. Visual source of truth is `design/locked/`.

## Stack

Bun, Next.js 16 (App Router, Turbopack), React 19, TypeScript 5.9, Tailwind CSS 4, shadcn/ui on Radix, Lucide, Phosphor, Motion, Lenis, next-view-transitions, Vaul, Embla, Zod.

Resume in the nav is a Drive link, not a page.

## Run

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
bun run build
bun start
```
